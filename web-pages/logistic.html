But to do glm regression we need a linear model

There exists a function called “logit”

\[g(p)=logit(p)=ln \left(\frac{p}{1-p}\right)\]

That is useful because…

\[ \begin{align} \mu=p &= \color{blue}{g^{-1}(\eta)}==\frac{1}{1+exp[-(\beta_0+\beta_1x)]} \\ \\ logit(p)&=\color{blue}{g(p)} = \eta=\beta_0+\beta_1x \end{align}\]
